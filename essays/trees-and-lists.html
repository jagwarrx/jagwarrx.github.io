Think in Trees, Do in Lists

November 2026. 446 words.

The fundamental organizational problem of my ADHD brain is that it thinks like a mind map: in trees, not in a line like a list. One thought opens three more, each of those opens three, and every branch is interesting.

Execution doesn’t work that way. Time runs in one line, and I can only do one thing at a time. So the idea is to separate the two. When I’m thinking, I think in mind maps. When I’m executing, I force a list, and do it one item after another.

Trees are good for thinking

A tree is how the thinking actually arrives, so fighting it throws away the best part. A mind map lets an idea go where it wants, shows how things connect, and puts the whole shape of a problem on one page. Nothing has to be in order yet. Jumping between branches is the point.

Trees are bad for doing

A tree has no “next”. Every node has several children, and each one is a decision: which branch now? Work from a tree and every step is a fork.

Halfway through one task I see a sibling branch, follow it, and come back to three half-finished things. Each open branch is an open loop, and attention goes to whatever is new, so the newest branch pulls hardest.

A list has one answer to “what now?”: the next line.

The step between: flatten

Between the two modes is one step: turn the tree into a list. Pick the leaves that are real tasks, leave the rest on the map, and put the tasks in order. Order is priority. The decisions get made here, once, so none are left for the doing.

Then force the line

While executing, the list is the only shape in front of me, and I take one thing at a time, top down. New branches still come, because that’s how the brain works. They don’t get followed. Each one becomes a single line in a parking spot and waits for the next thinking session.

If the list stops making sense, that’s the signal to stop executing and go back to the map. On purpose, as its own session, not as a branch in the middle of a task.

Two modes, two shapes

This is the split from a list of lists, one item at a time, one level up. There it was the data: wide for organizing, narrow for doing. Here it’s the mind: trees for thinking, a line for doing.

The fix isn’t to make the brain linear. It’s to give each mode the shape it needs, and to switch between them on purpose.
