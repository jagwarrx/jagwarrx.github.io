When This, Do That

November 2026. 594 words.

When this, do that. That’s the whole art of planning ahead to reduce friction.

The plan isn’t a forecast of the day. It’s a set of decisions made early, each tied to a moment: when it’s nine, open the draft; when this block ends, take the next line. When the moment comes, the decision is already made, and there’s nothing left to do but start.

Friction is decisions

Most of what stops me from starting isn’t the work. It’s the questions in front of it. What now? When? For how long? How do I start? What counts as done? Each one is small. Together they’re the wall.

The moment of doing is the worst time to answer them. That’s when I’m tired, distracted, or already pulled toward something easier, and the in-the-moment levers are exactly the ones an ADHD brain is short of. So I move the decisions earlier, to a calm moment, and answer them all at once.

The form is a trigger and an action: when this, do that. Peter Gollwitzer calls these implementation intentions, and his work finds that deciding the response in advance makes it far more likely to happen. I wrote about using them for the situations that keep coming back in Know How You’ll Meet It. Here they do a plainer job: getting an ordinary day started.

What to decide ahead

What. Three things for today, in order. Not more.

When. A time, not a day. “Tuesday” is a wish. “Tuesday at ten” is a trigger.

How long. A set length for the block, picked before it starts. A block that ends is easier to begin than a task that doesn’t.

How to start. The first step, written down. “Write the essay” is a project. “Open the draft and write the first line of section two” is a start.

When it’s done. For anything bigger than a day, the finish line, written before the work begins. Without it there’s no end, and a task with no end is hard to start.

When to look again. Anything waiting on someone else gets a date to check back. Then it’s a line in the plan, not a worry.

What next. The next item already in line, so finishing one thing flows into the next thing, not into a search.

What not to plan ahead

Capture. Writing a new thing down has to cost nothing: a name and Enter. If a new item needs a time, a length and a project before it can be written, it doesn’t get written. Planning happens later, at a set time. Flattening the map into a list is part of the same sitting.

The night before, ideally

The best time to plan is the night before. The day just done is still fresh, so I know what’s left and what’s real. Picking means looking at everything, and looking at everything is the overwhelming part. In the evening it’s over before the day starts. And a plan lets the mind let go: Masicampo and Baumeister found that making a specific plan for an unfinished goal quiets the thoughts about it.

Then the morning starts with an action, not a decision.

The test

In the moment, the only question left should be: start? If I catch myself deciding anything else, that’s a decision the plan missed. I don’t fix it then. I note it, and plan for it next time.

And when the plan breaks, which it will, the rule is already there too: when the plan breaks, take the next line.
