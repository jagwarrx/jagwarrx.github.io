Not Tools, but Automation

November 2026. 606 words.

The usual answer to an attention problem is a tool. A new app, a timer, a tracker, a better list. For managing attention, I think that’s the wrong shape of answer. What helps is not tools, but automation.

A tool asks for attention

To get anything from a tool, I have to do four things. Remember it exists. Open it. Operate it. Keep it up to date.

Each of those is a request for attention, which is the one thing I’m short of. While the tool is new, novelty covers the cost. When the novelty goes, the requests are still there, and out of sight is out of mind: a tool I don’t open doesn’t exist.

So a tool for attention has a strange problem. It needs the thing it was supposed to supply.

Start with the list

Instead of tools, create the list. Open a text file and create the list. That’s where you start.

It takes no setup, and nothing has to be learned first. And a plain text file is something any agent can read and change, so the automation has something to work on from the first day.

Automation gives it back

Automation runs whether or not I remember it. It does the remembering, the sorting and the timing, and it puts the result in front of me.

A reminder that fires at a set time. An inbox that gets sorted overnight. A brief that arrives every morning with the three things for today. None of them wait to be opened.

The test

One question separates the two: does it still work on a day I forget it exists?

If yes, it’s automation. If it needs me to open it, it’s a tool, however clever it is.

Why this is attention management

Managing attention mostly means managing what’s in front of me, because whatever is in view becomes the obvious next thing. I can’t do that by effort, minute by minute. Something has to do it for me.

That’s the job I want automation to have. Put the right few things in front of me at the right time, and keep everything else out of sight. The organizing happens where I can’t see it, and my attention goes to the work.

Don’t touch the tasks

The same goes for the task list itself. I don’t touch the tasks. I only chat to the agent, and the agent does all the updates.

In the minimum system, I touch the big list only on weekends. That’s the version with no automation. This is the automation piece on top of it: with an agent, I don’t touch the list at all.

I say what happened: this is done, this is new, this moved to Thursday. The agent changes the list. I don’t open it to edit it, because opening it means seeing all of it, and seeing all of it is where the sorting starts.

A chat line is the smallest way in that I know. One sentence, no fields, and no deciding where it goes.

What still needs me

Choosing. I pick what matters. The automation delivers it.

The work itself.

And some care in what I automate. Each automation is one more thing that can stop without my noticing, so I want few of them, each doing one job, each showing its result where I’ll see it. Before automating anything, I do it by hand for a week. If it didn’t help by hand, it won’t help on a schedule.

A tool is something I have to pay attention to. Automation is something that pays attention for me.
