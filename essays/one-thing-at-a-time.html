One Thing at a Time

November 2026. 531 words.

Most of what I’ve written about constraints is about the ones I already have. This is about one I add on purpose: I can do only one thing at a time.

The rule

One thing at a time. Not one thing a day. One thing in front of me until it’s done, or until it reaches a stopping point.

It sounds like a limit, and it is one. But every constraint creates a question, and this one swaps a bad question for a good one. Without it, the question running in the background is “what else should I be doing right now?” That question has no end. With it, the question is “which one?” That one can be answered.

Pick from options

The usual version of this rule is “do the most important thing first.” It fails for me, because it names one specific thing, and I might not feel like doing that one specific thing. I run on novelty, not importance. Hand me exactly one task and the easiest move is to do none.

So the one thing comes from options. A short menu: three or four tasks, all of them worth doing. I pick the one I can feel like starting now.

The menu does two jobs. It turns an order into a choice, and a choice is much easier to say yes to. And it makes mood safe. If every option on the menu is worth doing, picking by how I feel can’t go wrong.

Don’t drop what you started

A menu has a cost. If I can choose once, I can choose again. Start one thing, feel the pull of another, switch, and the day ends with four things started and none done. The new option always looks better than the one in hand, only because it’s new.

So the rule has a second half. Once I pick, the menu closes. The choice is spent. It opens again when the thing is done or at its stopping point, and not before.

All the freedom sits before the start. After the start there is none. That’s the trade, and it’s a fair one: I got to choose.

Focus on the start

The start is where neurospicy minds get tripped. Not the work. Once a task is moving it mostly keeps moving. The trouble is the gap before it: choosing, opening the thing, making the first move.

So every part of the rule points at the start. One thing at a time means there is only one start to make. The menu means the start is something I chose. The closed menu means a start is never wasted, because what I start, I stay with.

It also changes what I ask of myself. Not “finish this.” Just “pick one, and begin it.” If the start happens, the rule carries the rest.

Why add a constraint at all

It looks backwards to fix a problem of doing too little by allowing myself less. But more freedom was never what was missing. Too many open things is its own kind of stuck. One thing, chosen from a few, kept until it’s done: two limits, with one free choice between them.
