Spruced Up Planka

November 2026. 802 words.

Planka is an open-source kanban board that looks like Trello and runs on my own machine. The free Community edition is good. The calendar, the timeline and the rest of what I wanted are in the paid Pro edition.

So I made my own copy of Community 2.3.1. Its licence allows that for personal use. I kept the look exactly and wrote every new feature from scratch, without Pro’s code. It has one user: me. This is the list of what changed.

Time

  • Calendar view across all my projects or just one: month, week, three days and a single day. Drag a card to another day.
  • Timeline view: a bar from each card’s start to its due date. Drag to move it, drag an end to resize.
  • Day calendar beside the board: drag a card or a task onto a time slot, as many times as it needs. A To schedule list shows what has no time yet.
  • Start dates on cards and due dates on tasks.
  • Repeating cards: closing one makes the next.

Boards

  • Every board starts with the same four lists: Backlog, Next, Doing, Done.
  • Swimlanes: Today, This week and Later, worked out from due dates and sessions. Dropping a card in a lane sets its date. Backlog and Done don’t split.
  • Lists can be added and renamed in the swimlanes view too.
  • Plain Trello-style background colours for boards.

Home

  • My own headings instead of the fixed groups; drag projects between them.
  • View all: one kanban for a whole heading, with lists of the same name merged.
  • A project opens the board I used last. Edit mode stays on.
  • Cmd+K searches projects, boards and cards.

Cards

  • Estimates: tasks pick 1, 2, 3, 5 or 8; a card takes any number or adds up its tasks.
  • Typed custom fields: text, number, date, checkbox, dropdown and link.
  • Templates: mark a card as a template, then start new cards from it on any board.
  • A card can link a project, so a card on one board opens another project.
  • A done button on each card, and video attachments that play.

Focus blocks

Blocks follow the Block Method.

  • Start block asks one question first: how will I start? Then a 25-minute countdown shows on the card and in the top bar.
  • At the end, a short log: what I did, with an editable start time. Blocks live in their own section on the card.
  • Log block records a block I ran on paper, without the timer, for when I log the block instead of starting it.
  • The top bar shows blocks done today against the day’s target.
  • A weekly report: blocks per board per day, targets for each day and each board, what is left this week, and a copy button for a spreadsheet.
  • Each board can have a total and a due date. The report shows the current rate, the rate needed, and when I’ll finish at this pace.

One user

  • Logs in by itself on my machine.
  • Hides members, joining, subscribing and the other team features.

Next

A dark theme, selecting several cards at once, quick capture by pasting, and a dashboard page to start the day.

Where it sits

Planka adds a layer on top of the minimum viable tool: planning and resource management. Its job is to let me hold only the work in progress in my attention at one time. In the layers of effectiveness:

LayerQuestionTool
Strategy, outputsWhat deserves time?Visual strategy planner: objectives across time, and progress on each (projects and objectives)
Plans and objectivesWhat this week, when, and how much?Planka: calendar, timeline, swimlanes, estimates, a block budget for each board
Focused workAm I actually doing it?The minimum: do a block, log it, count it against a target
EnergyDo I have the fuel?Habits

The minimum runs the focused work. Planka manages the resource. Time is fixed and counted in blocks, so the job is deciding where the blocks go: which project gets how many this week, on which day, and whether the rate is enough for the due date. What isn’t in progress stays on the board, so I don’t have to hold it.

The order matters. Fixing a lower layer from a higher one is fragile. If the blocks aren’t happening, more planning won’t fix it. The minimum has to run first, and Planka helps only once it does.

Why bother

Stock Planka is a good surface. What I needed was time: which card, when, for how long, and whether I’m on pace. Building on an app I already liked kept the parts that worked and let me add only those. It is the same list with a better surface.
