About

  • I build AI agents for production and craft software tools.
  • Mostly the parts a demo skips: messy inputs, interruptions, handoffs to a person.
  • AI Practice Lead at qBotica since 2023. Before that, 3 years at Amazon (Alexa, AWS).
  • MS CS, Arizona State · B.Tech, NIT Trichy.
  • Hackathons, improv, meditation, chess.

Work

  • Logistics voice agent · Takes inbound and outbound calls, creates and changes quotes during the call, and routes callers. Python · LiveKit
  • Document extraction · LLM structured extraction across 200+ form types. Python · LLMs
  • Banking agents · Pilots at a national US bank: claims processing, syndicated lending, enhanced due diligence. Agents · evaluation
  • Résumé agent · Screens 5,000+ résumés a day against job requirements. LLMs · FastAPI
  • Alexa routing debugger · Shows why Alexa routed a shopping request where it did. Adopted across Alexa teams. Amazon · Java · React
