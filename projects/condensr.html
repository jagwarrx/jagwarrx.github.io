Condensr rebuild

A visual thinking canvas, rebuilt in the browser from an open-source desktop tool I liked.

Status
paused
When
November 2025 to January 2026
Stack
React, React Flow, Vite. Data in the browser, later as YAML files
Original
Condensr, a free Java desktop app from the x28hd family of thinking tools

What it does

A canvas of spaces inside spaces. Each space holds concept and text nodes, boxes and arrows, and reference nodes that point into other spaces, so one idea can live in several maps at once. I added what I wanted from a daily tool: an inbox, a Today, Later and Done task list, a timeline, and a focus mode.

Why I rebuilt it

I liked how the original let me think spatially, but it's a desktop Java app and I wanted to change it. The first version was one 4,000-line React file; the second split it into modules and moved the data to plain YAML files I could read and version.
