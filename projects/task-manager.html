Personal OS

Eighteen attempts at a system to run my life, and what the two survivors have in common.

Status
active
Started
2025
Stack
Everything from single-file HTML and React to SQLite, Obsidian plugins and a command-line tool. What survived: Things 3 and a plain text log
For
Me

What it is

Tasks, projects, habits, a calendar and a review, in whatever shape I believed was right that month. Versions have included a single-file HTML app with Miller columns, kanban, calendar and gantt views; a React and SQLite app that wrote every card out as a markdown note under git; a self-hosted Roam clone; an Obsidian vault with fifteen task plugins; and a SQLite database with a command-line tool and twenty-two views.

What happened

Between September 2025 and August 2026 I started eighteen of them. The median one lasted four days, and none reached day twenty-eight. In one, the task I'd worked on most was "update this app". In another, a third of all the time it ever tracked was spent building it.

What survived

Two things, and neither has a schema. (The longer version is an essay.) Things 3, which I've used continuously since September 2025. And an append-only log: dated entries, free-form, no checkboxes. Versions of that log outlived the system around them five separate times.

Plain HTML. No tracking. Last updated September 2026.
